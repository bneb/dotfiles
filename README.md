# Dotfiles

Developer environment configuration utilizing Neovim, Tmux, Alacritty, and local LLMs.

## Commands

### 1. Editor & Navigation
*   **`v` / `vim`**: Launches Neovim.
*   **`..` / `...`**: Directory traversal.
*   **`z` (zoxide)**: Directory jumping (e.g., `z proj`).
*   **`ls` / `ll` (eza)**: Directory listings.
*   **`cat` (bat)**: File viewing with syntax highlighting.

### 2. Local AI
Local inference infrastructure using Ollama.
*   **`gemma`**: Gemma 4 (9B) chat.
*   **`gemma-vision`**: Gemma 4 (12B Multimodal) chat.
*   **`gemma-pro`**: Gemma 4 (26B) chat.

### 3. Searching
Fuzzy finding and text search.
*   **`vf`**: Fuzzy find file and open in Neovim.
*   **`sf`**: Fuzzy find file and output path.
*   **`rf` (ripgrep)**: Text search (e.g., `rf "function hello"`).

### 4. Git
*   **`gst`**: `git status -s`
*   **`ga`**: `git add .`
*   **`gcm "message"`**: `git commit -m "message"`
*   **`gca`**: `git commit --amend --no-edit`
*   **`gco <branch>`**: `git checkout`
*   **`gcb <branch>`**: `git checkout -b`
*   **`glg`**: `git log --graph`
*   **`gp` / `gl`**: `git push` / `git pull`

### 5. Tmux
Terminal multiplexing. Prefix is mapped to `Ctrl+a`.
*   **`kx`**: Attach to or create `workspace` session.
*   **`tl`**: List sessions.
*   **`ta <name>`**: Attach to session.
*   **`Ctrl+a c`**: New window.
*   **`Ctrl+a 1, 2, 3`**: Switch windows.
*   **`Ctrl+a %`**: Split vertical.
*   **`Ctrl+a "`**: Split horizontal.
*   **`Ctrl+a h/j/k/l`**: Navigate panes.

## Architecture

*   **`install.sh`**: Deployment script. Installs Homebrew, evaluates `Brewfile`, and symlinks configs.
*   **`bin/setup-ssh`**: GitHub SSH key generation.
*   **`bin/setup-llm`**: Ollama and Gemma provisioning.
*   **`.macos`**: macOS default configurations.
*   **`.profile`**: PATH and environment variable definitions.
*   **`.zshrc` / `.bashrc`**: Shell configurations and aliases.
*   **`.tmux.conf`**: Multiplexer configuration (Catppuccin theme).
*   **`.gitignore_global`**: Global git ignores.
*   **`alacritty.toml` / `starship.toml`**: Terminal and prompt configuration.

## Installation

1. Clone repository:
   ```bash
   git clone https://github.com/yourusername/dotfiles.git ~/dotfiles
   cd ~/dotfiles
   ```
2. Generate SSH keys:
   ```bash
   ./bin/setup-ssh
   ```
3. Run deployment script:
   ```bash
   ./install.sh
   ```
4. Provision local AI:
   ```bash
   ./bin/setup-llm
   ```
5. Apply macOS settings:
   ```bash
   ./.macos
   ```

Note: API keys and local secrets should be placed in `~/.zshrc.local` (generated by `install.sh`), which is excluded from version control.
